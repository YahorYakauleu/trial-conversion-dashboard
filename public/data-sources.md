# Откуда берутся данные и как они связываются

Дашборд ничего не берёт из нашей базы — данные приходят напрямую из API Stripe и Solidgate. Для каждого триала собирается одна строка: когда оформлен и закончился, какой платёж первый, прошёл ли он и с какой попытки, был ли рефанд, какая карта. Отдельно хранится каждая попытка списания первого платежа.

## Коротко: цепочки связей

**Stripe:** Подписка ← Инвойс ← Списание ← Рефанд

- инвойс знает свою подписку, списание — свой инвойс, рефанд — своё списание;
- карта — у клиента подписки (карта по умолчанию).

**Solidgate:** Подписка → её инвойсы → их попытки (orders) — всё приходит в одном отчёте подписок.

- отчёт заказов дополняет: к подписке — по `subscription_id` (карта), к попытке — по `order_id` (код отказа, рефанд).

## Stripe

| Что берём | Зачем | Как связываем с триалом |
|---|---|---|
| **Подписки** | Сам триал: даты начала и конца | Это и есть триал — если у подписки заполнены `trial_start` и `trial_end` |
| **Клиент → карта по умолчанию** (в том же запросе, что подписки) | Страна, способ оплаты (Apple Pay / Google Pay / карта), платёжная система | Клиент подписки. Банк Stripe для наших аккаунтов не отдаёт |
| **Инвойсы** | Первый платёж: оплачен ли, когда, с какой попытки | Инвойс ссылается на подписку. Первый платёж — инвойс продления (`subscription_cycle`) с суммой больше нуля, созданный в момент конца триала (± час; позже суток — уже не первый) |
| **Списания (charges)** | Попытки оплаты первого инвойса, причины отказов, рефанды | Списание ссылается на инвойс. Берём только списания первого платного инвойса триала |
| **Рефанды** | Вернули ли деньги за первый платёж | Рефанд ссылается на списание |
| **События** «инвойс оплачен» / «оплата не прошла» | Ежедневное обновление: кто оплатил на ретрае | Как инвойсы |

Как отвечаем на вопросы по триалу:

- **Сконвертился?** — первый инвойс оплачен не позже 30 дней после конца триала.
- **С первой попытки?** — инвойс оплачен первой попыткой и в течение часа после выставления. Проверка времени нужна, потому что ручная оплата после отказа выглядит в Stripe как «первая попытка». Если хоть раз видели отказ первой попытки, это уже не меняется.
- **Попытки и отказы** — каждое списание первого инвойса — одна попытка: прошло или отклонено, с кодом причины от банка или антифрода.
- **Рефанд** — по успешному списанию первого инвойса вернули деньги (полностью или частично).

Тонкость: в текущей версии API Stripe у списания нет ссылки на инвойс, поэтому списания запрашиваются в версии API от 20.06.2024, где она есть.

## Solidgate

| Что берём | Зачем | Как связываем с триалом |
|---|---|---|
| **Отчёт подписок** | Триал, инвойсы и попытки — всё внутри одной подписки | Триал — подписка на продукт с пробным периодом, которая реально стартовала (есть `started_at`). Без него — карта не прошла проверку при оформлении, триала не было |
| ↳ **Инвойсы подписки** | Первый платёж | Первый платный инвойс — с номером периода 1 и выше (0 — сам триал) и суммой больше нуля |
| ↳ **Попытки (orders) этого инвойса** | Прошёл ли платёж, с какой попытки, рефанд | Лежат внутри инвойса. Успех — `settle_ok` / `approved` / `refunded`; «в процессе» пока не считаем |
| **Отчёт заказов (card-orders)** | Карта (страна, способ оплаты, система, банк), код отказа, сумма рефанда | Данные карты — по `subscription_id` заказа. Код отказа и рефанд — по `order_id`: это тот же id, что у попытки в отчёте подписок |

Как отвечаем на вопросы по триалу:

- **Когда закончился триал?** — дата старта + длина триала продукта (например, 10080 минут = 7 дней).
- **Сконвертился?** — у первого платного инвойса есть успешная попытка не позже 30 дней после конца триала.
- **С первой попытки?** — самая ранняя попытка этого инвойса успешна.
- **Рефанд** — попытка в статусе «возвращено» или в отчёте заказов есть сумма рефанда.
- **Способ оплаты** — из заказа (Apple Pay / Google Pay / карта). У списаний по сохранённой карте (`token`) — способ, которым карту сохранили (`original_payment_method` транзакции).

Тонкость: заказ оформления создаётся на секунды раньше подписки и может попасть в предыдущие сутки, поэтому заказы забираются с запасом в час.

## Сводная таблица

| Вопрос | Stripe | Solidgate |
|---|---|---|
| Это триал? | у подписки есть даты триала | у продукта есть триал, подписка стартовала |
| Когда закончился? | дата конца триала у подписки | старт + длина триала продукта |
| Какой платёж первый? | первый инвойс продления после триала | первый инвойс с номером периода ≥ 1 |
| Оплачен? | инвойс оплачен | есть успешная попытка |
| Попытки | списания первого инвойса | orders первого инвойса |
| Причина отказа | код отказа списания | код ошибки заказа |
| Рефанд | у списания есть возврат | статус «возвращено» или сумма рефанда |
| Страна, способ, система | карта клиента по умолчанию | карта из заказа |
| Банк | — (Stripe не отдаёт) | банк карты из заказа |

## Оборот

Оборот — это все успешные списания, а не только первые платежи после триала.

| Что берём | Откуда | Как |
|---|---|---|
| **Stripe** | Все списания (charges) аккаунта — те же, что для попыток | Успешные и захваченные. Сумма — из balance transaction: столько Stripe зачислил, уже в USD. Страна, способ оплаты и система — с карты самого платежа |
| **Stripe, рефанды** | Рефанды | Обновляют возвращённую долю платежа |
| **Solidgate** | Отчёт заказов (card-orders) | Заказы с суммой больше нуля в статусе `settle_ok` или `refunded`. MID — поле `mid`, сумма — в валюте процессинга, возврат — `refunded_amount` |
| **Курсы валют** | Публичный API дневных курсов ([currency-api](https://github.com/fawazahmed0/exchange-api)) | Только для заказов Solidgate не в USD; курс на день платежа, сохраняется в базе |

## Как обновляется

- **Первая загрузка** — все подписки, оформленные с даты начала отчёта (сейчас 1 сентября), их инвойсы и попытки. Идёт по дням, после обрыва продолжает с того же места.
- **Каждый день** (и по кнопке «Обновить») — только то, что появилось с прошлого синка:
  - Stripe — новые подписки, события по инвойсам, новые списания и рефанды, с запасом в час (Stripe отдаёт данные сразу). Занимает 1–2 минуты, повторный запуск — секунды;
  - Solidgate — изменившиеся подписки и заказы, с запасом в сутки (отчёты Solidgate могут отставать на пару часов). Заказы — по дате изменения, поэтому доходят и рефанды старых платежей. Занимает до минуты.
- Уже известные данные не стираются пустыми: если, например, оплата один раз найдена, повторная выгрузка без неё её не удалит.

## Что не берём

- Продления в конверсии — там только первый платёж после триала (в обороте продления есть).
- Чарджбэки и диспуты.
- Страну по IP — используем страну карты.
- Нашу базу (workflow-service) — данные только из платёжных провайдеров.
